## 🎯 الفكرة

موضوعٌ واحد، أربع نوافذ (لِينُكس · ماك · ويندوز · BSD)، وقصّةٌ تجمعها. كلّ كتابٍ يبدأ من الصفر المطلق، ويبني بأسلوب **مفهوم ← جرّب بنفسك ← تحدٍّ**، ويجسِّر إلى شقيقاته. «العين تقرأ قبل العقل» — فالجمال أولويّة لا ترف.

## 🗂️ بنية المستودع

```
command-line-series/
├── lib/              ← نظام التصميم المشترك (Typst): ألوان، خطوط، قالب، صناديق
├── books/
│   ├── 1-linux/      ← «مِن الصِّفر إلى الجَذر» — لِينُكس
│   ├── 2-macos/      ← «ماك من الطرفية» — macOS
│   ├── 3-windows/    ← «مِن الصِّفر إلى المسؤول» — ويندوز
│   ├── 4-bsd/        ← «مِن الصِّفر إلى العِفريت» — BSD
│   ├── 5-workbook/   ← «الطرفيّةُ بالممارسة» — دفتر التمارين
│   └── 6-unix-story/ ← «رُوحٌ في الآلة» — حكاية يونِكس
│         (كلّ كتابٍ فيه ar/ · frontmatter/ · assets/ الأغلفة)
├── docs/             ← دليل الأسلوب، خارطة الطريق، دليل الهوية البصرية
├── fonts/            ← خطوطٌ حرّة مثبَّتة (بناءٌ متطابقٌ على أيّ جهاز)
├── tools/            ← مولّد EPUB والهيكل
└── build.sh          ← يبني الكتب الستّة (PDF) إلى build/
```

## 🛠️ البناء

يعتمد على [Typst](https://typst.app)، والخطوطُ الحرّة مثبَّتةٌ داخل `fonts/` (IBM Plex Sans Arabic، Noto Kufi Arabic، JetBrains Mono) فيخرج البناءُ متطابقًا على أيّ جهاز.

```bash
./build.sh              # يبني الكتب الستّة (PDF) إلى build/
./build.sh 1-linux      # يبني كتابًا بعينه
```

توليدُ EPUB (اختياريّ، للقراءة على الجوّال):

```bash
python3 tools/make_epub.py books/1-linux/ar build/zero-to-root-ar.epub
```
