# خارطة الطريق · Roadmap

## الحالة الحالية

يجري إعداد النسخة 1.3 بعد النسخة 1.2 المنشورة. يشمل النطاق الأساسي
خريطة تراخيص دقيقة، وCC BY-SA للمحتوى العام المحدد، وMIT للشيفرة
الأصلية المحددة، وإفصاح الذكاء الاصطناعي، وسياسة الترجمة، وتصحيحات
تاريخية جراحية للكتاب السادس. لا يصبح الإصدار منشورًا قبل اعتماد صاحب
المشروع.

## الأعمال الاختيارية التالية

1. صيانة الوثائق والروابط وREADME.
2. جولات مراجعة تقنية أو لغوية إضافية دون تغيير المحتوى المعتمد تلقائيًا.
3. تحسين أدوات البناء وتوليد EPUB والتحقق من المخرجات.
4. إصدار نسخ جديدة عند اعتماد تغييرات فعلية، مع تحديث CHANGELOG.
5. إعداد ترجمات عبر الدليل والمسار الرسمي، مع بقاء الترجمات المجتمعية
   ممكنة وفق CC BY-SA.
6. نقل الملفات الداخلية المنشورة سابقًا إلى مستودع خاص بعد قرار صاحب المشروع.

## خارج النطاق الحالي

- إعادة كتابة الكتب من الصفر.
- إعادة بناء ملفات PDF أو EPUB دون سبب موثق.
- إدخال مستوى خبير جديد في الكتب الستة الحالية.
- حزمة الطباعة التجارية وملفات interior المتقدمة.
- برنامج وصول PDF موسع وتوسيع CI الكامل.
- إطار الحوكمة والخلافة؛ وهي بنود مؤجلة إلى إصدار لاحق.
