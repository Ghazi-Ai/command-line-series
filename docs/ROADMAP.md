# خارطة الطريق · Roadmap

## الحالة الحالية

الإصدار 1.3 معتمد ومنشور. الكتب الستة متاحة بصيغة PDF، والكتاب السادس
متاح أيضًا بصيغة EPUB، والموقع وقارئ الويب يعملان من أصول الإصدار
المنشور.

## الأعمال الاختيارية التالية

1. صيانة الوثائق والروابط وأدوات البناء.
2. تحسين الوصول والطباعة عند وجود متطلبات واضحة.
3. إصدار نسخ جديدة عند اعتماد تغييرات فعلية، مع تحديث CHANGELOG.
4. إعداد ترجمات عبر الدليل والمسار الرسمي، مع بقاء الترجمات المجتمعية
   ممكنة وفق CC BY-SA.

## خارج النطاق الحالي

- إعادة كتابة الكتب من الصفر.
- إعادة بناء المخرجات دون تغيير يستدعي ذلك.
- إضافة التزامات إصدار بلا قرار واضح من صاحب المشروع.
