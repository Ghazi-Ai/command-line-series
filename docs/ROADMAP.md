# خارطة الطريق · Roadmap

## الحالة الحالية

الإصدار 2.0.0 معتمد ومنشور. اكتملت السلسلة في عشرة كتب تشمل أنظمة
التشغيل، والممارسة، وحكاية يونيكس، والأتمتة، وإدارة الخوادم، والشبكات،
والمشروعات المتدرجة. تتوفر الكتب بصيغ PDF وEPUB ومتون مستقلة
للطباعة، وتخضع لفحوص إصدار فعلية في CI.

## الأعمال الاختيارية التالية

1. اعتماد قيم المطبعة الفعلية لكل غلاف ممتد عند طلب نسخة تجارية:
   عرض الكعب، والنزف، واتجاهه، ونظام الألوان ومعيار PDF.
2. اختبار عينة طباعة فعلية قبل الإنتاج التجاري.
3. تحسين الوصول مستقبلًا عند توفر متطلبات اختبار وقارئات محددة.
4. إعداد ترجمات عبر الدليل والمسار الرسمي، مع بقاء الترجمات المجتمعية
   ممكنة وفق CC BY-SA.

## خارج النطاق الحالي

- إعادة كتابة الكتب من الصفر.
- إعادة بناء المخرجات دون تغيير يستدعي ذلك.
- إضافة التزامات إصدار بلا قرار واضح من صاحب المشروع.
