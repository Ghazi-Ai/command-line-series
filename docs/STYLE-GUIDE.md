# دليل الأسلوب · Style Guide

هذا الدليل يحفظ وحدة الصوت والتصميم عبر الكتاب كلّه. اقرأه قبل كتابة أيّ فصل.

## الصوت واللغة

- **من الصِّفر المطلق:** المتطلّب الوحيد للقارئ أن يعرف القراءة والكتابة. لا تفترض أيّ معرفةٍ سابقة؛ عرّف كلّ مصطلحٍ عند أوّل وروده.
- **فصحى راقية، دافئة، دقيقة.** لا لهجات عاميّة. تجنّب التقعّر والغموض.
- **التشبيه قبل التجريد:** ابدأ الفكرة الصعبة بتشبيهٍ من الحياة (المطعم، البيت، النادل...)، ثم جرّدها.
- **الأرقام:** عربيّة هنديّة (١، ٢، ٣) في المتن؛ وتبقى غربيّة (0‑9) داخل الأوامر والأكواد والمسارات.

## بنية الفصل (إلزاميّة)

كلّ فصلٍ يتبع هذا الهيكل:

1. `#chapter[العنوان]` — يفتح الفصل ويرقّمه آليًّا.
2. `#objectives((...))` — «في هذا الفصل ستتعلّم»: ٣–٥ أهداف.
3. فقرةٌ افتتاحيّة (تشبيه/تشويق).
4. أقسام `#section[..]` و`#subsection[..]`، وفيها: **مفهوم ← مثال تجرّبه ← صندوق `#try-it`**.
5. `#section[خلاصة الفصل]` — تلخّص وتربط بالفصل التالي.
6. `#challenge[..]` — تحدٍّ ختاميّ يطبّق فكرة الفصل.

## دوال القالب (استعملها، لا تنسّق يدويًّا)

| الدالة | الاستعمال |
|--------|-----------|
| `#chapter[..]` | عنوان الفصل (مرقّم آليًّا) |
| `#section[..]` / `#subsection[..]` | العناوين الفرعية |
| `#part(ord, title)` / `#appendix(letter, title)` | الأجزاء والملاحق (في `_contents.typ`) |
| `#objectives((..))` | أهداف الفصل |
| `#challenge[..]` | تحدّي الفصل |
| `#define(term, body)` | تعريف مصطلح |
| `#session(cmd, output: ..)` | جلسة طرفية بمحثّ `$` |
| `#kbd("Ctrl")` | مفتاح لوحة مفاتيح |

## الصناديق ومتى تستعملها

- `#note[..]` معلومة جانبية إثرائيّة.
- `#tip[..]` حيلة توفّر وقتًا.
- `#warn[..]` خطأ شائع أو مفاجأة.
- `#danger[..]` فعلٌ مدمّر لا رجعة فيه (حذف، كتابة فوق قرص...).
- `#distro[..]` بديل الأمر على أرش/فيدورا (اصطلاح التوزيعات أدناه).
- `#try-it[..]` تمرينٌ عمليّ فوريّ — **عنصر أساسيّ في كلّ فصل**.
- `#ethics[..]` حدٌّ أخلاقيّ/قانونيّ — إلزاميّ عند كلّ أداةٍ حسّاسة في فصول الأمن.
- `#deep[..]` استطرادٌ متقدّم يمكن تجاوزه.

لا تُكثر من الصناديق حتى لا تفقد وقعها؛ الصندوق استثناءٌ لا قاعدة.

## اصطلاح التوزيعات

- **دبيان/أوبونتو** هي الأساس في المتن (`apt`, `systemctl`...).
- عند كلّ اختلافٍ جوهريّ، أضف `#distro[..]` بالبديل على أرش (`pacman`) وفيدورا (`dnf`).
- الفصل ١٢ هو المرجع الكامل لمديري الحزم.

## الأكواد

- استعمل أسوار ```` ```bash ````؛ القالب يجعلها يساريّة LTR داخل إطار.
- التعليقات داخل الكود بالعربية مقبولة ومستحبّة للتوضيح.
- في المتن، أحِط المحارف الخاصة (`*`، `>`، `|`) بعلامة LRM ‏(‎U+200E)‎ أو ضعها في كود مضمّن `` `..` `` كي لا يفسّرها Typst.
