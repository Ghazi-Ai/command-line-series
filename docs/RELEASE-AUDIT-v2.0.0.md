# تقرير تجميع وفحص الإصدار 2.0.0

تاريخ الفحص: 2026-07-31. خط الأساس المنشور قبل هذه الجولة هو
`7a9f777` (`v1.4.1`). يجمع الإصدار 2.0.0 الكتب العشرة في إصدار واحد،
ويضيف الكتب 7–10 إلى البناء والموقع والقارئ وحزمة التنزيل.

هذا التقرير سجل تقني وتحريري، وليس رأيًا قانونيًا أو شهادة فسح أو
اعتمادًا من دار نشر أو جهة حكومية. لا يدعي المشروع خلو الكتب من كل
خطأ، ولا يخترع اسم ناشر أو ISBN أو رقم إيداع.

## النطاق المنفذ

- تدقيق عدائي مستقل للكتب 8 و9 و10، مع إغلاق الملاحظات القابلة
  للتعيين في العربية والدقة التقنية والأمن وحدود التفويض.
- إدخال الكتب 7–10 في بناء PDF وEPUB ومتون الطباعة ومولد الغلاف
  الممتد وGitHub Actions.
- توحيد أغلفة الكتب العشرة على هوية الورق العتيق، مع صورة متفردة
  لكل كتاب، وتحديث صور README والموقع.
- تثبيت بطاقة اسم رقّية بشفافية 50٪ على الأغلفة الأمامية العشرة كي
  يبقى «المهندس غازي السيف — أبو هيثم» مقروءًا فوق تفاصيل الرسم،
  وتوحيد عنوان الكتاب العاشر في الغلاف وصفحة العنوان على سطرين.
- تحديث الإصدار والأرقام والروابط وصفحة المشروع ومكتبة الموقع إلى
  عشرة كتب و3,482 صفحة.
- إضافة رزمة أغلفة تفاعلية إلى واجهة الموقع وضبطها لشاشات الهاتف
  الطولية، مع تجديد كاش صور الأغلفة وصفحات القارئ بعد التصحيح.
- اختبار قارئ الويب فعليًا في متصفح Chromium على سطح المكتب والهاتف،
  بما في ذلك فتح الكتاب والانتقال من الصفحة الأولى إلى الثانية.
- مراجعة خريطة الحقوق والإفصاح وإخلاء المسؤولية وحدود الطباعة
  والتداول، مع إبقاء المسائل الرسمية التي تحتاج جهة مختصة خارج
  الادعاءات المنجزة.

- الكتاب الثامن: صُححت دقة متوسط الحمل وقراءة `/proc`، وتقوية SSH
  والنسخ الاحتياطي وملكية ملفات الخدمة وقيود `systemd`، وتحذير
  Docker مع UFW، وسلوك المؤقتات. التقرير المفصل في

  اسم المضيف في OpenSSL، وحُصرت المختبرات في عناوين وبيئات آمنة
  موثقة. التقرير المفصل في
  `docs/audits/book-9-adversarial-v2.0.0.md`.
- الكتاب العاشر: صُحح اختبار مرشح النشر ونظافة Git ومختبر الشبكة
  ومؤقتات `systemd` وتصادم النسخ والحدود الأمنية للملفات والأسرار.
  يضم الكتاب 21 مشروعًا متدرجًا. التقرير المفصل في
  `docs/audits/book-10-adversarial-v2.0.0.md`.

## الحقوق والإفصاح والنشر

- المحتوى العام المسمى صراحة في `LICENSES/README.md` تحت
  CC BY-SA 4.0، والشيفرة الأصلية المسماة تحت MIT، ومواد الأطراف
  الثالثة تحت رخص أصحابها. لا تنطبق رخصة واحدة على المستودع كله.
- الإفصاح العام وداخل الكتب وEPUB يقرر أن جميع مسودات الكتب ونصوصها
  الأساسية وُلّدت باستخدام أدوات الذكاء الاصطناعي، مع بيان دور غازي
  السيف ومسؤوليته عن القرارات التحريرية، ومن دون نسبة صفة المؤلف إلى
  الأنظمة.
- صور الأغلفة مولدة عبر ChatGPT Images وفق إقرار صاحب المشروع
  الموثق، بلا مدخلات بصرية خارجية معلنة، ثم نُسقت في Typst. الصور
  مستثناة من CC BY-SA 4.0، ويحدد `COVER-PERMISSION.md` الإذن المحدود
  بطباعة وتوزيع النسخة الرسمية غير المعدلة ككتاب كامل. لا يضمن ذلك
  حصرية الصور ولا يسجل حقًا أو علامة.
- لم تضف المراجعة دار نشر أو مطبعة أو ISBN أو رقم إيداع أو فسحًا.
  تبين `docs/PUBLISHING-CHECKLIST.md` ما يلزم التحقق منه قبل الطباعة
  أو التداول في المملكة، مجانيًا أو بمقابل.
- يلزم صاحب المشروع سؤال مكتبة الملك فهد الوطنية أو الجهة المختصة
  عن انطباق الإيداع على ملفات PDF وEPUB المجانية المنشورة عبر GitHub؛
  لا يدعي هذا التقرير أن إصدار GitHub يفي بالإيداع.

## الفحوص المنفذة

- `make check`: نجح، ويشمل تركيب Bash وPython واختبارات مشروع الكتاب
  السابع وفحص تاريخ الرخصة و`git diff --check`.
- `make release`: نجح في بناء 10 ملفات PDF و10 متون طباعة و10 ملفات
  EPUB بالإصدار 2.0.0.
- `make release-check`: نجح لجميع الكتب؛ تطابقت أعداد الصفحات، ونجح
  Ghostscript، واختبار ZIP وXML/XHTML/OPF والفهرس وRTL والحقوق
  والإفصاح في EPUB.
- `pdfinfo` و`pdffonts`: البيانات الوصفية موجودة، ومقاس الملفات A5،
  وجميع الخطوط المستعملة في ملفات PDF مضمّنة.
- المعاينة البصرية: الغلاف وصفحة العنوان والحقوق والمقدمة والغلاف
  الخلفي للكتب العشرة، وصفحات الحقوق بالحجم الأكبر، ومعاينة غلاف
  ممتد؛ لم يظهر تداخل أو خروج معروف عن الهوامش. وتحقق استخراج اسم
  صاحب المشروع من الصفحة الأولى للملفات العشرة بعد إضافة بطاقة الاسم.
- الموقع: نجح تحميل الصفحة بلا أخطاء JavaScript في الاختبار، ونجح
  قارئ الكتابين 7 و10 على سطح المكتب والهاتف في الانتقال إلى الصفحة
  الثانية مع العدد الصحيح للصفحات.
- فُحصت نسخ إجراءات GitHub Actions وصحة YAML، وثبت وجود الإصدارات
  المشار إليها في مستودعات `actions/*` الرسمية.
- فحص الأسرار: GitHub Secret Scanning غير مفعل للمستودع وقت الفحص.
  شُغّل Gitleaks 8.30.1 بعد التحقق من checksum الرسمي على الشجرة
  الحالية وعلى تاريخ Git؛ لم يسجل أي نتيجة. كما روجعت نتيجتا بحث
  محافظ يدويًا واتضح أنهما مثالان تعليميان وهميان لا أسرارًا.

## الحدود والمخاطر المتبقية

- التحقق النظامي من الإيداع والفسح والبيانات المطلوبة قرار تنفيذي
  عند النشر الورقي أو عند جواب الجهة المختصة عن الإصدار الإلكتروني.
- يلزم اعتماد عينة مطبوعة ومواصفات المطبعة الفعلية للألوان وPDF/X
  والنزف والكعب والورق والتجليد؛ ملفات المتن صالحة للفحص التقني وليست
  موافقة من مطبعة بعينها.
- نجاح استخراج النص وRTL لا يساوي ادعاء توافق وصول كامل؛ توضح
  `docs/PDF-ACCESSIBILITY.md` القيود، وتبقى HTML وEPUB أولويتي الوصول.
- تتغير الأدوات والأنظمة وخدمات الاستضافة؛ يجب على القارئ مراجعة
  توثيق الإصدار الذي يستخدمه والعمل فقط ضمن ملكيته أو تفويضه.
- توثيق مصدر مخرجات الذكاء الاصطناعي لا يضمن التفرد أو الحصرية، ولا
  يمثل فحص تشابه شاملًا مع كل الأعمال الموجودة.
