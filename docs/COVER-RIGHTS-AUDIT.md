# تدقيق مصدر أغلفة الكتب وحقوقها

هذه الوثيقة سجلُ إثبات، لا إقرارُ ملكية ولا مراجعةٌ قانونية. تثبت
ملفات المشروع وجود تعليمات لتوليد الفن الأساسي بأدوات توليد الصور،
ثم إضافة النصوص والتخطيط بأداة Typst، لكنها لا تحفظ اسم الأداة أو
النموذج أو الحساب أو الشروط السارية لكل أصل. لذلك تبقى صور الأغلفة
مستثناةً من عرض CC BY-SA 4.0 للإصدار 1.3 إلى أن يكتمل السجل.

## الأدلة المتاحة وحدودها

- يصف `covers/README.md` برومبتات توليد فنٍّ بلا نص، ثم إضافة النص
  لاحقًا.
- يصف `docs/دليل-الهوية-البصرية.md` إمكان إعادة التوليد بأداة صور
  ويحيل إلى Typst للتخطيط.
- تحفظ `covers/front/` و`covers/back/` الصور المستعملة، وتحفظ الكتب
  نسخًا منها في `books/*/ar/assets/`.
- لا تتضمن الملفات المتاحة سجلَّ طلبات التوليد الفعلية، أو اسم
  الخدمة والنموذج، أو إثبات الحساب والخطة، أو الشروط المؤرخة، أو
  قائمةَ الصور المدخلة.

استثناء الأغلفة من CC BY-SA لا يثبت تلقائيًّا حق الاستخدام التجاري؛
يلزم إكمال سجل المصدر وشروط الأداة المستخدمة. لا يمنع هذا بناء النسخ
الرقمية للفحص، لكنه مانعٌ أمام اعتماد الطباعة التجارية النهائية حتى
يتخذ صاحب المشروع قرارًا موثقًا.
