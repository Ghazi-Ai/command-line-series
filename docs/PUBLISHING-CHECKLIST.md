# قائمة تحقق النشر والطباعة

توثّق هذه الصفحة ما تحقّق منه المشروع في الإصدار 2.0.0، وما يبقى
إجراءً على صاحب المشروع أو الناشر أو المطبعة. وهي ليست استشارة
نظامية، ولا شهادة فسح، ولا موافقة من جهة حكومية أو دار نشر.

## ما يثبته المستودع

- اسم صاحب المشروع ودوره والإفصاح الصريح عن توليد المسودات والنصوص
  الأساسية بأدوات الذكاء الاصطناعي.
- خريطة دقيقة تفصل المحتوى العام تحت CC BY-SA 4.0 عن الشيفرة تحت
  MIT ومواد الأطراف الثالثة والأصول البصرية المستثناة.
- سجل مصدر الأغلفة ومدخلاتها وحدود الحكم عليها.
- ملفات PDF وEPUB وملفات متن للطباعة، مع فحوص تقنية موثقة في مسار
  الإصدار.
- تنبيهات للأوامر عالية الأثر، وحدود واضحة للمختبرات الأمنية
  المأذونة، وإخلاء مسؤولية تعليمي.

## ما لا يدّعيه المشروع

- لا يذكر اسم دار نشر أو مطبعة أو رقم ISBN أو رقم إيداع أو رقم فسح
  ما لم يصدر فعلًا من الجهة المختصة.
- نشر GitHub لا يثبت وحده استيفاء متطلبات الطباعة أو التداول التجاري
  في بلد معين.
- نجاح البناء والتدقيق الآلي لا يساوي مراجعة قانونية أو أمنية مهنية،
  ولا يضمن خلو المحتوى من كل خطأ.
- توثيق توليد الأغلفة لا يضمن حصرية الصور أو تسجيل حق أو علامة.

## قبل الطباعة أو التداول داخل المملكة العربية السعودية

يشمل التداول هنا التوزيع المجاني والعرض للبيع معًا. على صاحب المشروع
أو الناشر الفعلي التحقق وقت التنفيذ من الإجراءات
والبيانات المطلوبة لدى الجهة المختصة. يقرر نظام المطبوعات والنشر، من
بين أمور أخرى، تدوين البيانات الورقية اللازمة على المطبوعة، وتقديم
نسخ للإجازة قبل الطباعة أو التداول، ومسؤوليات المؤلف والناشر والطابع،
كما يرتبط النشر المطبوع بمتطلبات الإيداع النظامي. لا يحاول هذا
المستودع تنفيذ تلك الإجراءات أو استبدالها.

قبل إرسال ملف نهائي إلى المطبعة:

1. حدّد الطرف الذي سيظهر ناشرًا والطرف الذي سيطبع؛ لا تستعمل اسم دار
   أو مطبعة قبل اتفاقها وموافقتها.
2. تحقّق من الفسح والبيانات الورقية والإيداع وأي رقم معياري مطلوب.
3. اطلب من المطبعة قيم النزف وعرض الكعب ونوع الورق والتجليد ونظام
   الألوان ومعيار PDF، ثم ابنِ الغلاف الممتد بهذه القيم فقط.
4. راجع نسخة إثبات مطبوعة، وصفحة الحقوق، وترتيب الغلاف الأمامي
   والخلفي والكعب، قبل إنتاج الكمية.
5. إن طُلب توثيق حق المؤلف، فخدمة تسجيل المصنفات المكتوبة لدى الهيئة
   السعودية للملكية الفكرية مسار توثيق اختياري مستقل عن رخصة
   CC BY-SA وعن إجراءات النشر.

## نقطة تحقق للإصدار الإلكتروني

نطاق نظام الإيداع لا يقتصر نصه على الكتب المباعة أو المطبوعة، ولذلك
لا يفترض المشروع أن نشر PDF وEPUB مجانًا عبر GitHub يعفي تلقائيًا من
الإيداع. يلزم صاحب المشروع سؤال مكتبة الملك فهد الوطنية أو الجهة
المختصة عن انطباق الإيداع ورقم الإيداع على هذا الإصدار الإلكتروني،
والاحتفاظ بالجواب. لا يصف المستودع إصدار GitHub بأنه مستوفٍ للإيداع
قبل هذا التحقق الرسمي.
