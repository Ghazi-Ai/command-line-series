# وثائق سلسلة سطر الأوامر

هذا المجلد يجمع وثائق عامة وملفات عمل داخلية سبق نشرها. مصادر الكتب
نفسها موجودة في `books/`، أما ملفات PDF وEPUB الناتجة فتُبنى داخل
`build/` ولا تُتعقّب في Git.

رقم إصدار المشروع محفوظ في `VERSION`، وإصدار أداة التنضيد المعتمد محفوظ
في `TYPST_VERSION`.

## الأدلة الأساسية

- `STYLE-GUIDE.md`: اللغة والصوت وقواعد كتابة الفصول.
- `ROADMAP.md`: حالة الإصدار والعمل اللاحق.

## ملفات داخلية مستثناة من عرض الترخيص 1.3

تشمل الملفات الداخلية البرومبتات وتعليمات العمل وتقارير التدقيق
والمخططات والمواد التي تتضمن طريقة توليد الأغلفة. لم تُحذف أو تُنقل في
الإصدار 1.3، لكنها ليست ضمن عرض CC BY-SA أو MIT الجديد، وهي مرشحة
للنقل إلى مستودع خاص في مهمة لاحقة.

لا ينطبق CC BY-SA على `docs/**` بصورة شاملة. المرجع الحصري للملفات
العامة المشمولة والاستثناءات هو [`LICENSES/README.md`](../LICENSES/README.md).
