# وثائق سلسلة سطر الأوامر

هذا المجلد يجمع وثائق التحرير والتصميم والتدقيق. مصادر الكتب نفسها موجودة
في `books/`، أما ملفات PDF وEPUB الناتجة فتُبنى داخل `build/` ولا تُتعقّب
في Git.

رقم إصدار المشروع محفوظ في `VERSION`، وإصدار أداة التنضيد المعتمد محفوظ
في `TYPST_VERSION`.

## الأدلة الأساسية

- `STYLE-GUIDE.md`: اللغة والصوت وقواعد كتابة الفصول.
- `SERIES-SPINE.md`: الهيكل المشترك للكتب التقنية.
- `WORKBOOK-SPINE.md`: هيكل كتاب «الطرفيّة بالممارسة».
- `دليل-الهوية-البصرية.md`: نظام التصميم والأغلفة.
- `ROADMAP.md`: حالة الإصدار والعمل اللاحق.

## تقارير التدقيق

- `تقرير-التدقيق-العدائي-للكتب-1-5.md`: تدقيق الكتب التقنية وكتاب التمارين.
- `تقرير-التدقيق-النهائي-للكتاب-السادس.md`: تدقيق «رُوحٌ في الآلة».

البرومبتات وملفات المهام في هذا المجلد سجلات عمل مساعدة، وليست مصادر
للنص المنشور.
