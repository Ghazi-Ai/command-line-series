# الإبلاغ عن مشاكل أمنية · Security policy

## العربية

إذا وجدت مشكلة أمنية في أدوات المشروع أو إعداداته، يرجى عدم نشر تفاصيلها في Issue عام. أرسل وصفًا خاصًا إلى صاحب المستودع عبر وسائل التواصل المتاحة في ملف [AUTHORS.md](AUTHORS.md)، مع خطوات إعادة المشكلة وأي أثر متوقع.

هذا المشروع عبارة عن سلسلة كتب ومواد تعليمية، ولا يقدم خدمة شبكية أو نظام مصادقة. لذلك تتركز البلاغات الأمنية المتوقعة على الروابط، الملفات المرفقة، أو الأدوات البرمجية.

## English

If you discover a security issue in the project tools or configuration, please do not disclose details in a public Issue. Contact the repository owner privately using the information in [AUTHORS.md](AUTHORS.md), including reproduction steps and the expected impact.

This repository is primarily a book series and educational material. It does not provide a network service or authentication system, so security reports are most likely to concern links, distributed files, or helper tools.
